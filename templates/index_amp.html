Expected Input Format:
  • Required Columns: Metal Color, Description, Stamping Instruction, Vendor Style, Order Qty, PURCHASE ORDER#, REMARK, Fulfil by Date, Metal Type, Size, Category
  • Optional Columns: Amipi Style
Output Format:

The processed Excel file will contain these columns:

  • SrNo, StyleCode, ItemSize, OrderQty, OrderItemPcs
  • Metal, Tone, ItemPoNo, ItemRefNo, StockType, MakeType
  • CustomerProductionInstruction, SpecialRemarks
  • DesignProductionInstruction, StampInstruction
  • OrderGroup, Certificate, SKUNo
  • Basestoneminwt, Basestonemaxwt, Basemetalminwt, Basemetalmaxwt
  • Productiondeliverydate, Expecteddeliverydate
Style Code Logic:

StyleCode is generated using:

  1. First checks against the master file (CS_100826/AMP_CS_120826.xlsx) using Vendor Style and Metal Type
  2. If not found, builds a structured code: VendorStyle-SizeTone
  3. Missing codes are automatically added to the master file
Metal Codes:
  • G14Y: 14KT Yellow Gold
  • G14W: 14KT White Gold
  • G18Y: 18KT Yellow Gold
  • G18W: 18KT White Gold
